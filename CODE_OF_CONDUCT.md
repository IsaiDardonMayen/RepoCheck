# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) como código de conducta.

En resumen:

- Trato respetuoso y empático con todas las personas.
- Críticas constructivas sobre el trabajo, nunca sobre las personas.
- Sin acoso, discriminación ni lenguaje ofensivo.
- Aceptar la responsabilidad de los errores propios y aprender de ellos.

Para reportar una conducta inaceptable, usa los avisos privados de GitHub del repositorio (Security → Report a vulnerability) o escribe a la persona que mantiene el proyecto.
